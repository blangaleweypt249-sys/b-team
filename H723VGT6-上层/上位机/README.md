# H723VGT6 上层控制台

这是 `H723VGT6-上层` 的 PC 端控制程序，使用 Tkinter 绘制界面，使用 `pyserial` 访问 CH340N 对应的虚拟串口。界面分为四个可切换页面：

- 机械臂：达妙 J4310 + 两个 M3508
- 闸门：一个 M2006
- 夹爪：一个 M2006
- 遥控控制：按遥控器 PD13/PD12/PD11/PD8/PD9/PD10 的电机动作按钮，以及三路气缸和 PB8/PB9 电子急停状态按钮

“遥控控制”页列出各按键涉及的电机角度，需要切换的动作同时列出第二次/复位目标。修改后点击“保存参数”会校验并保存到 `motor_parameters.json`，下次启动上位机时自动恢复；随后点击动作按钮才会下发目标。“全部归零”会用一条不更新 PID 的绝对位置命令，同时把 J4310、两台 M3508、闸门 M2006 和夹爪 M2006 送回各自的 `0 deg` 零位，并清除动作按钮状态。气缸与电子急停按钮统一显示“执行”，当前输出状态由按钮下方的状态文字显示。电机命令仍走无线 DAP 的 H723 PC 协议；辅助输出使用 `MSG_AUX_CONTROL (0x15)` 送到 H723，再由 H723 通过 UART5 发送完整 8 字节控制包到 F103 UART2。

实体遥控按键和“遥控控制”页使用同一组机构输出轴角度：

| 按键 | 动作 | 第一次动作 | 第二次动作/复位 |
| --- | --- | --- | --- |
| PD13 | 存块 | M3508 `500 deg`，J4310 `90 deg` | M3508 `1050 deg`，J4310 `90 deg` |
| PD12 | 取地面一层块 | M3508 `0 deg`，J4310 `90 deg` | M3508 `850 deg`，J4310 `90 deg` |
| PD11 | 收块 | 先将 M3508 移到 `0 deg`，等待 `0.5 s` 后仅将 J4310 移到 `165 deg` | 先将 M3508 移到 `0 deg`，等待 `0.5 s` 后仅将 J4310 移到 `240 deg` |
| PD8 | 翻转块/特殊块 | 先将 M3508 移到 `0 deg`，等待 `0.5 s` 后仅将 J4310 移到 `40 deg` | M3508 `0 deg`，J4310 `-20 deg` |
| PD9 | 闸门 | `180 deg` | `60 deg` |
| PD10 | 夹爪 | `55 deg` | `135 deg` |
| PC1 | 闸门到位后停止发送 | 闸门目标 `80 deg`；实际角度进入 `79..81 deg` 后失能 | 按 PD9 重新使能并继续原有闸门控制 |

夹爪表中的角度是夹爪机构输出轴角度；发送到 C610/M2006 前会按末级 `2:1` 减速比换算为电机侧角度。

板端直接读取 PE4、PE0、PD6 当前高低电平，不再使用 PE0/PD6 变化沿翻转模式。PE0=`1` 选择自动、PE0=`0` 选择手动；PD6=`1` 选择存三、PD6=`0` 选择存二，因此当前电平 `11` 是存三自动，`01` 是存三手动，`10` 是存二自动，`00` 是存二手动。上层对 PE0、PD6 分别连续确认 3 帧后才接受新档位；普通按键、普通开关和 `switch_bits.bit4` 的 PD6 兼容镜像均不参与模式计算，遥控链路暂时不可用时也不会强制改模式。PE0 或 PD6 当前电平使模式发生切换时，旧模式未完成的流程、延时和 PD13/PD12/PD11/PD8/PD9/PD10 单双次状态都会清除，因此返回任何模式后各按键都从第一段开始；各模式分别保留首次自动 PE4 联动历史。存二自动中 PC0、PD13、PD12 三者第一次触发存放类操作时，会联动执行第一次按 PD10 的夹爪动作：夹爪到 55°并推进 PD10 切换状态，所以下一次实际按 PD10 时夹爪到 135°；存三自动保留原有行为。存三手动 PD11 按 `0/165 deg`、`0/240 deg` 两段交替，第三次按下重新执行第一段；存二手动 PD11 始终只执行第一段 `0/165 deg`。

PC1 在四种模式中均为闸门停止动作：识别按下上升沿后先使能闸门 M2006 并下发 `80 deg` 目标，持续读取机构输出轴反馈；实际角度进入含边界的 `79..81 deg` 区间后立即禁用闸门，底层发送一次停止命令并停止周期输出。PC1不会改变PD9的单双次状态；之后按PD9会取消尚未完成的PC1待失能动作、重新使能闸门，并继续当前PD9对应的 `180 deg/60 deg` 控制。

PC0 只在存二自动和存三自动中生效。三个分支按 `第一 -> 第二 -> 第三 -> 第一` 循环，起步目标依次为 `500/90 deg`、`0/90 deg`、`850/90 deg`。存二自动每个分支均等待手动关闭 PE4 后到 `0/90 deg`，再按 PC0 将闸门固定到 `180 deg`，等待 `500 ms` 后到 `0/-20 deg`；最后手动打开 PE4 后立即依次下发闸门=`68 deg`、M3508=`0 deg`、J4310=`90 deg`，普通 PD9 下一次均从 `180 deg` 开始。存三自动打开 PE4 后直接执行收尾动作，不再等待额外 `200 ms`。第一次手动关闭 PE4 前连续按 PC0 会立即切换并下发下一分支起步目标，可连续循环切换。第一分支启动时自动打开 PE4；若 PC0 是存二自动本模式第一次存放类操作，同时执行第一次 PD10 的夹爪动作（55°），下一次实际按 PD10 将到 135°；存三自动保留原有首次夹爪联动。自动模式中按 PD13、PD12 或 PD11 会保留该按键原功能，同时取消 PC0 当前流程并把下一次 PC0 复位到第一分支。存二手动和存三手动均忽略 PC0。

存二自动和存三自动模式中，非翻转模式下的 PD13、PD12、PD11 分别执行自动流程。PD13 第一次按下会清除 PD12、PC0 尚未完成的当前流程，但保留两者的已按历史。PD13 或 PD12 的分支一完成后，下一次按同一个键会直接执行该键分支二；进入分支二后再次按同一个键，会取消分支二并重新执行第一次按下的第一段目标。存二自动 PD13 分支一第一次按下到 `500/90 deg`，自动打开 PE4；等待手动关闭后 M3508 立即回 `0 deg`，`0.5 s` 后 J4310 到 `180 deg`，分支一结束；关闭前再次按 PD13 则直接进入分支二。若在该 `0.5 s` 收尾期间按 PD13，系统会记住本次按键，并在收尾完成后自动进入分支二，无需再按。存二自动和存三自动的 PD13 分支二均执行 `M3508=1050 deg/J4310=70 deg`；PE4 手动关闭后 M3508 回 `0 deg`，等待 `0.5 s` 后分别收尾到 `180 deg` 和 `165 deg`。存二自动 PD12 分支一执行 `0/90 deg`，自动打开 PE4；手动关闭后 M3508 保持 `0 deg`，等待 `0.5 s` 后 J4310 到 `180 deg`。PD12 分支二执行 `850/90 deg`，收尾为 `0/180 deg`。存二自动本模式中 PC0、PD13、PD12 三者首次存放类操作共用一次 PD10 首段夹爪联动：夹爪到 55°并把下一次实际 PD10 推进到 135°。存二自动 PD11 使用 `200 ms` 窗口区分单击和双击：单击在窗口结束后执行 `M3508/J4310=500/90 deg`、闸门=`40 deg`，再等待 `1000 ms`，即首次按下约 `1.2 s` 后自动打开 PE4，同时回到 `M3508/J4310=0/180 deg`，流程结束且不自动关闭 PE4；双击在第二次按下时取消当前 PD13/PD12 自动流程，立即执行 `M3508/J4310=1050/90 deg`、闸门=`40 deg`，再等待 `1.5 s` 后自动打开 PE4并回到 `0/180 deg`，流程结束。单击同时将普通 PD9 的下一次动作复位为 `180 deg`。存三自动保留原有 PD13/PD12/PD11 流程。PD9/PD10 保持手动功能，普通 PD9 闸门在 `180 deg` 与 `60 deg` 之间切换；PD8 翻转流程以本文件后面的“PD8 翻转模式当前规则”为准。

上位机目标和实体遥控目标共用板端同一条位置驱动链路：J4310 统一经过五次多项式位置轨迹、零 `v_des` 和基于最新实际角度的实时重力补偿；M3508/M2006 统一进入各自驱动内的 1 ms 五次多项式位置轨迹，不会因为控制来源不同而改用位置阶跃。

UART 辅助帧格式为 `A5 5A 01 02 01 seq control_bits crc8`，CRC8 多项式为 `0x07`，计算范围为字节 2 到 6。`control_bits` 低四位是输出状态，高四位是本次更新掩码；两组 bit0/1/2 分别对应接收板 PB3/PB5/PB7，bit3 对应 PB8 和 PB9。上位机按钮只更新被点击的一路，自动流程只更新 PB3，因此不会在操作普通气缸时覆盖其它实体遥控输出或解除电子急停。每个合法帧都按掩码明确写 GPIO；状态 bit0 使用 `0=打开/高电平、1=关闭/低电平`，bit1/bit2 使用 `0=低、1=高`，bit3 使用 `0=PB8/PB9 高、1=PB8/PB9 低`。H723 每次动作连续发送三个相同控制状态、不同序号的完整帧，重复写入相同电平不会重复翻转；高四位为 0 的旧帧保持原兼容语义，即 PB3 明确更新、其余三路仅更新状态值发生变化的通道。

遥控链路使用当前已经部署的固定 10 字节帧 `A5 5A + 8 字节数据`：字节 6 的 bit1 对应 PC1，字节 7 的 bit0 对应 PE0，字节 8 的 bit0..5 对应 PD13、PD12、PD11、PD8、PD9、PD10，字节 9 的 bit0/1/2/4/5 对应 PE4、PE3、PE1、PD6、PD5。

## PD8 翻转模式当前规则

存二自动和存三自动共用以下翻转子流程。翻转模式内按 PD13，首段目标为 `M3508=500 deg/J4310=90 deg`；按 PD12，首段目标为 `M3508=0 deg/J4310=90 deg`。首段都会自动打开 PE4，等待手动关闭 PE4（`0 -> 1`）后均先等待 `200 ms`，再将 M3508 回 `0 deg`、J4310 到 `180 deg`。存二自动中闸门 M2006 保持原目标，不再回 `0 deg`；关闭后按 PD13 或 PD12 均可确认当前首段收尾，M3508 到 `500 deg`、J4310 到 `40 deg`，等待 `1.5 s` 后自动打开 PE4，当前子流程结束但仍保持翻转模式。`200 ms` 内的确认键和 `1.5 s` 内的新分支按键都会被锁存，不会再丢失按下沿。存三自动保持原闸门回零和同键确认规则。

首段尚未手动关闭 PE4 时，再按 PD13 或 PD12 会推进当前活动子流程：PD13 进入 `M3508=1000 deg/J4310=90 deg`，PD12 进入不变的 `M3508=850 deg/J4310=90 deg` 第二段；PD12 第二段不增加首段的 `200 ms/1.5 s` 延时，也不追加 `180 deg`。自动存二和自动存三中，本轮第一次按 PD13 或 PD12 时同时执行一次夹爪首次 PD10 目标 `55 deg`，下一次实际 PD10 为 `135 deg`。翻转模式中按 PD13 会把下一次 PD12 复位为第一段，按 PD12 会把下一次 PD13 复位为第一段。

## 启动

Windows 上双击 `启动上位机.bat`，或在当前目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

Python 3.10 或更高版本可用。串口为 UART4，参数为 `115200 8N1`。浏览器不参与串口访问，因此不需要额外的本地服务器。

## 目标与软件零位

上位机不再显示“使能”或“允许输出”控件，只保留“发送目标”“停止发送”“保存参数”和急停。“保存参数”位于“停止发送”右侧，按电机保存当前目标和控制参数到 `motor_parameters.json`；下次启动会恢复这些值，闸门与夹爪 M2006 各自独立保存。串口已经握手时，保存会在同一次点击中立即下发并应用；未连接时只保存，连接后点击“发送目标”应用。数值输入框只更新待发送参数，点击“发送目标”后直接下发；位置滑块按下后立即发送目标，拖动期间每 50 ms 刷新一次，松开时发送最终目标并保持。J4310 位置范围为 `-90 deg..+270 deg`，M3508 独立位置输入、同步输入和同步滑块范围均为 `0 deg..1200 deg`，两台 M2006 的上位机目标范围为 `-360 deg..+360 deg`。闸门 M2006（FDCAN3 ID 1）和夹爪 M2006（FDCAN3 ID 2）仍按页面独立下发。两个 M3508 保留各自独立的位置目标输入；同步输入或同步滑块值为 `x` 时向 M3508 #1 和 #2 都提交 `x`。连接期间的握手与心跳只维护串口链路，不包含新的电机目标。按下空格键或点击“急停”按钮都会立即发送独立的急停命令；按住空格不会重复发送。急停让板端向所有已配置电机发送一次停止，撤销全部周期输出和旧目标授权，整机进入 `ROBOT_STOP`，不会进入或锁存 `ROBOT_ERROR`，串口会话也保持有效。急停后不会自动恢复旧目标，重新点击“发送目标”只会恢复该次目标明确选择的电机；先断连再重新连接后同样可以继续控制。急停期间电机单独重新上下电，或主控和电机一起重新上电，都不会留下急停锁存；J4310 收到新目标后会重新发送使能帧并等待使能反馈。

J4310 和两台 M2006 的角度输入旁各有联动滑块；两台 M3508 使用两个独立目标输入、一个同步输入和一个公共同步滑块。J4310 的 MIT 协议位置能力范围仍为 `-12.5..+12.5 rad`，上位机位置控件保持 `-90 deg..+270 deg`；`0 deg..180 deg`只作为本次在线调参的测试区间，不作为软件限位。J4310 操作行显示最近一次反馈的输出轴编码器角度，板端单位 `rad`，界面转换为 `deg`；角度会保留到断连或重新握手，反馈是否仍新鲜由旁边状态单独表示。点击“永久标定”会先停止所有电机，再向 J4310 发送保存当前位置为永久零位的 `0xFE` 动作，并在运行日志显示板端成功或失败回执。

所有数值输入框按界面声明范围限制键入和粘贴；发送目标前还会执行一次独立校验，防止程序赋值或未完成输入绕过控件限制。超限目标不会写入串口，界面会弹出错误参数、当前值和全部允许范围。J4310 还额外要求 `|tau| <= 力矩限幅 <= 10 Nm`。“参数范围”按钮可随时查看目标、MIT 和 PID 输入范围。停止发送和急停不受目标参数校验影响。

J4310 旁的“重启归零”开关只保存在 H723 当前运行期的 RAM 中，不读写 Flash。H723 每次上电或复位后开关固定为关闭，因此 MCU 重启和重启后的首次 J4310 反馈都不会触发归零。开关开启后，只有 H723 已经见过 J4310 在线、随后仅 J4310 掉电导致反馈中断、再恢复反馈时，固件才会用带速度和加速度限制的连续位置轨迹把输出轴平滑带回电机自身的永久零位 `0 rad`，归零后保持零位。H723 在 RAM 中持续保存 J4310 最后一个原始角度和展开后的逻辑角度；电机单独重启后，板端按相邻角度差小于 `180 deg` 的条件补偿 `360 deg` 分支，并将相同圈偏移同时用于反馈与后续位置命令。例如掉电前为 `90 deg`、重连单圈反馈为 `-160 deg` 时，逻辑角度恢复为 `200 deg`，回零命令沿当前电机圈映射为 `-160 deg -> -360 deg`，对应机构的 `200 deg -> 0 deg`。这些角度和圈偏移均不写入 Flash，H723 重启后清空；若 J4310 掉电期间实际转动达到或超过 `180 deg`，仅凭掉电前后两个单圈值无法唯一恢复方向和圈数。开启开关本身不会移动在线电机；手动发送 J4310 目标、停止、急停或执行永久标定都会立即释放本次自动归零控制。急停不会改变运行期开关，但 `ROBOT_STOP` 期间单独重启 J4310 不会自动归零或自行恢复输出；收到新目标恢复运行后，后续再次发生的 J4310 掉电重连仍可触发归零。其他四台电机的操作不会释放 J4310 自动归零。

M3508 的独立目标、同步输入和同步滑块范围均为 `0 deg..1200 deg`，M2006 机构上位机目标范围为 `-360 deg..+360 deg`。板端将 M3508 #1 的协议方向设为正向、#2 设为反向，因此两个相同符号的位置目标会驱动机构同步运动。H723 每次重新上电、复位或初始化驱动后，四台 DJI 电机立即进入目标为 `0 deg` 的位置控制；在零点尚未建立时驱动只发送零电流。每台电机在接近静止时收到连续 5 帧稳定反馈后，把当前位置保存为本次上电的软件零点，随后开始保持该位置。C620/C610 不直接反馈减速器输出轴绝对角度，板端通过转子编码器累计变化量除以减速比得到相对角度。发送 `0 deg` 表示保持或回到本次 H723 上电位置；发送 `10 deg` 表示从该基准转到输出轴 `+10 deg`。软件零点不写入 Flash，电机反馈短暂中断和上位机连接不会重新标定。J4310 不把当前角度重映射为软件零点，而是以电机永久零位为坐标原点，并在 H723 RAM 中展开单圈反馈以保持电机单独重启前后的逻辑角度连续。

上位机分别显示 M3508 #1、M3508 #2、闸门 M2006 和夹爪 M2006 的“当前输出轴角度”“相对标定零点角度”“是否标零”及“反馈状态”。当前输出轴角度由标定零点对应的输出轴角度叠加累计相对角度得到，避免转子单圈编码器回绕后显示跳变；尚未标零时暂按当前转子单圈角度除以减速比显示，相对标定零点角度显示为 `-- deg`。四台电机通过独立短帧轮询刷新，单台约 `20 Hz`，避免无线串口截断原有长状态帧。若显示“未收到诊断，请烧录新固件”，说明 H723 仍运行旧版状态协议。

两台 C620 必须工作在 CAN 模式、使用 1 Mbps，并分别设置为 ID 1 和 ID 2；正常反馈标准帧 ID 分别为 `0x201` 和 `0x202`。若两台电调使用相同 ID，它们会读取同一个 `0x200` 控制槽位，并可能因同时发送相同仲裁 ID、不同数据而产生 CAN 错误。新版 DJI 短帧会回传三路 FDCAN 原始收帧计数；无反馈提示会区分 FDCAN2 总线无帧和总线上有帧但缺少当前电机反馈 ID。

板端初始化后，M3508/M2006 自动以本次上电位置为 `0 deg` 进入位置保持；J4310 自动使能并把首个有效反馈角度作为 MIT 位置目标，例如上电反馈为 `30 deg` 就持续位控在 `30 deg`。输入框目标只有在点击“发送目标”后才会下发，拖动位置滑块会直接控制对应电机。点击“停止发送”或急停会退出对应输出；断连、命令超时和反馈超时不再自动撤销已经下发的输出。

J4310 的 MIT `p_des`/`v_des` 是输出轴位置/速度，协议单位分别为 `rad` 与 `rad/s`；M3508 目标位置由转子角度按 `3591/187` 减速比换算为输出轴角度，M2006 按 `36` 减速比换算。J4310 的位置、速度、Kp、Kd、tau 和力矩限幅会在拖动位置滑块或点击“发送目标”时写入扩展位置帧；M3508/M2006 也通过这两种显式操作发送 `0x12` 命令，进入板端“位置环 -> 速度环 -> 电流命令”级联控制。

板端收到新的 J4310 位置目标后，不再把目标位置作为阶跃直接下发，而是从最新反馈角度生成五次多项式 `p_des` 轨迹。为避免抬升机构耦合运动引入速度前馈力矩，实际发送给 J4310 的 MIT `v_des` 始终为 `0 rad/s`；五次曲线只用于平滑位置目标。速度和加速度上限由 `UPPER_J4310_TRAJECTORY_MAX_VEL_RAD_S`、`UPPER_J4310_TRAJECTORY_MAX_ACCEL_RAD_S2` 约束，当前分别为 `3.7 rad/s` 和 `15 rad/s^2`，典型 0 到 90 度轨迹约为 `0.80 s`；上位机帧中的 J4310 `v_des` 字段为协议兼容保留。

J4310 的 MIT `tau` 用于重力前馈。单关节场景采用 `tau_g(q)=a*cos(q)+b*sin(q)`，它等价于重力通过雅可比转置 `J(q)^T F_g` 映射到关节，不额外引入完整 VMC。除 `0 deg +/-5 deg` 和 `180 deg +/-5 deg` 外，重力补偿按最新实际角度计算，并使用 `2 deg` 角度死区降低轻微移动引起的补偿变化；进入禁用区时重力 `tau` 立即清零，模型学习也暂停。新位置目标到达后，电机反馈转矩只在实际速度接近静止、没有人工 `tau` 且位置误差满足条件时更新 `a/b`；连续 100 帧保持在目标 `+/-1 deg` 内后冻结本目标的模型系数，收到新目标才重新开放学习，避免固定位置处反复补偿。在线学习率为 `0.02`，最终输出乘以 `1.5`，并以 `10 Nm/s` 限制补偿变化速度。最终命令为“人工 tau + 重力 tau”，并始终受人工力矩限幅和 `UPPER_J4310_GRAVITY_MODEL_LIMIT_NM` 双重限制；重新初始化会清空当前运行期模型。

首次发送目标前必须架空机构、确认机械限位和急停链路有效。当前已关闭通信和反馈看门狗，串口断开或反馈中断后，板端会继续保持最后一次有效目标，直到收到显式停止、急停、故障保护动作或设备掉电。

点击“连接”后，上位机会先发送 `HANDSHAKE (0x03)` 请求（payload 为 ASCII `H723`），并等待板端返回同序列号的 `ACK (0x7E)`（payload 同为 `H723`）。收到匹配 ACK 前界面保持等待状态，不会发送心跳或电机目标；收到 ACK 后开始发送空 payload 心跳，仍不会发送电机目标，也不会查询或显示 Flash 状态。握手重试始终使用同一个序列号。超过 3 秒仍未响应时，上位机保持串口打开并继续等待。握手成功后即使暂时收不到板端状态帧，也不会清除输出使能或自动重新握手。

界面中的“断连”只断开控制会话、停止所有周期发送，不关闭无线 DAP 的 CDC 串口；再次点击“连接”会复用同一个串口句柄并重新握手。这样主控和接收端无线 DAP 一起掉电、再上电时，不需要给电脑侧发送端重新上下电。电脑侧发送 DAP 被物理拔出或发生串口读写错误时，上位机会立即释放已经失效的 Windows 串口句柄并恢复“连接”按钮；重新插入后可直接再次连接，若 Windows 分配了新的 COM 号则先点击“刷新”。退出上位机，或者断连后选择其他串口/波特率再连接时，也会真正关闭原串口。

Horco 无线 DAP 的无线模块为半双工。进行 Keil 下载或调试时，DAP 会暂时关闭 CDC 虚拟串口，并在超过其 `CDC After DAP` 时间没有新调试数据后恢复。调试期间不要反复打开、关闭 COM 口；需要使用上位机时，应先退出 Keil Debug，并等待主机蓝灯和从机绿灯进入呼吸状态。升级到本版本后首次运行前，如果发送端已经处于无法透传的旧状态，仍需最后重启发送端一次；之后按上述流程不会再因界面断连而反复开关 CDC。

## PC 二进制协议

帧格式与 `User/Driver/PcLink/pc_protocol.c` 一致，所有多字节字段为小端：

```text
A5 5A | version(u8) | type(u8) | sequence(u16) | length(u16) |
payload(length) | CRC16(u16)
```

CRC16 为 Modbus CRC（初值 `0xFFFF`，多项式 `0xA001`），覆盖 `version` 到 payload 的全部字节。

| 类型 | 值 | 说明 |
| --- | ---: | --- |
| HEARTBEAT | `0x01` | 空 payload，维持远程链路 |
| ESTOP | `0x02` | payload 为 `01`，进入急停 |
| HANDSHAKE | `0x03` | payload 为 ASCII `H723`，请求建立控制链路 |
| UPPER_CMD | `0x10` | 原有 V3 速度命令，保持兼容 |
| UPPER_POSITION_CMD | `0x12` | 位置命令：兼容 34 字节，普通控制发送 122 字节扩展 payload，全部归零发送 42 字节无 PID payload |
| MOTOR_ACTION | `0x13` | J4310 维护动作；保存零点和仅使能为 3 字节 payload，重启归零配置为 4 字节 `action, can_bus, node_id, enabled` |
| ROBOT_STATE | `0x20` | 当前为 84 字节：基础状态、J4310 位置、RX/TX 诊断、运行期自动归零开关和状态；第 80 字节表示功能是否可用，上位机兼容旧版 20/25/50/80/89/101 字节 |
| DJI_TELEMETRY | `0x22` | 28 字节：单台 DJI 诊断和 3 路 FDCAN 原始 RX 计数；四台轮询发送 |
| ACK | `0x7E` | 握手确认：序列号与请求一致，payload 为 ASCII `H723` |

兼容位置命令 payload 为 `u16 enable_mask + 8 个 little-endian float`（34 字节），布局如下：

| 偏移 | 字段 | 单位 |
| ---: | --- | --- |
| 0 | 使能位：bit0 旧机械臂组合，bit1 闸门，bit2 夹爪，bit3 旧四路 DJI 同步，bit4 仅 J4310，bit5 仅两台 M3508，bit6 显式停止 J4310 | - |
| 2 | J4310 目标位置（输出轴角度） | rad |
| 6 | J4310 目标角速度（输出轴） | rad/s |
| 10 | J4310 基准 Kp | - |
| 14 | J4310 基准 Kd | - |
| 18 | M3508 #1 位置（输出轴角度） | rad |
| 22 | M3508 #2 位置（输出轴角度） | rad |
| 26 | 闸门 M2006 位置（输出轴角度） | rad |
| 30 | 夹爪 M2006 位置（输出轴角度） | rad |

“全部归零”发送 `u16 enable_mask + 10 个 little-endian float`（42 字节），携带 J4310 转矩字段和五台电机的独立位置目标，但不更新 DJI PID。普通控制发送 `u16 enable_mask + 30 个 little-endian float`（122 字节）的扩展位置命令。两者的前 10 个浮点顺序相同；与兼容布局相比，M3508/M2006 位置字段后移到浮点序号 6..9，122 字节帧再继续携带 PID：

| 浮点序号 | 字段 | GUI 单位 |
| ---: | --- | --- |
| 4 | J4310 `tau` | Nm |
| 5 | J4310 力矩限幅 | Nm |
| 6..9 | M3508 #1/#2、闸门、夹爪位置 | rad |
| 10..14 | M3508 速度环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |
| 15..19 | M3508 位置环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |
| 20..24 | M2006 速度环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |
| 25..29 | M2006 位置环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |

`0x10` 速度命令使用同样的偏移，但偏移 18/22/26/30 解释为 `rad/s`，并由原有速度模式处理。

## J4310 MIT 参数

板端 J4310 使用标准 8 字节 MIT CAN 帧，CAN 标准 ID 为电机逻辑 ID `0x06`，反馈 Master ID 为 `0x16`。`p_des` 与 `v_des` 均以 J4310 输出轴为基准，参数映射为：

上位机可编辑并发送全部 MIT 参数：`p_des`、`v_des`、`Kp`、`Kd`、前馈 `tau` 和力矩限幅。上位机默认 `p_des=90 deg`，上位机、实体遥控和启动保持统一以 `v_des=0 rad/s`、`Kp=30.0`、`Kd=0.95` 为在线调参基准；实际发送的 `v_des` 始终为零。误差超过 `1 deg` 时驱动根据位置误差、收敛趋势和实际速度实时调整 `Kp/Kd`，并严格保持 `Kp<50`、`Kd<1`；进入 `+/-1 deg` 且接近静止后恢复并保持基准值。`tau` 默认 `0 Nm`，力矩限幅默认 `10 Nm`；软件力矩限幅只裁剪 `tau`，不会改变协议映射；MIT 命令编码和反馈解码始终使用与达妙调试助手一致的固定 `TMAX=10 Nm`。

H723 上电后每 20 ms 重试发送 J4310 标准使能帧 `ID=0x006 / FF FF FF FF FF FF FF FC`，直到反馈 `data[0]高四位=0x1` 确认已使能。随后板端读取当前输出轴角度，并用 `Kp=30.0`、`Kd=0.95`、`v_des=0`、`tau=0` 发送 MIT 位置保持；它不会修改或保存 J4310 永久零点。上位机后续点击“发送目标”或拖动滑块会替换这个启动保持目标。

机械臂页只显示 J4310 反馈状态，不显示 Flash 状态、TX/RX 计数、最近 CAN 帧或拒绝明细。`0x0` 为未使能，`0x1` 为已使能，`0x2/0x3/0x5/0x7/0x8..0xE` 为电机异常或故障。

| 字段 | 范围 | 位宽 | 打包位置 |
| --- | ---: | ---: | --- |
| 目标位置 p | `-12.5 .. +12.5 rad` | 16 | data[0:1] |
| 目标速度 v | `-30 .. +30 rad/s` | 12 | data[2:3] |
| Kp | `0 .. 500` | 12 | data[3:4] |
| Kd | `0 .. 5` | 12 | data[5:6] |
| 前馈力矩 τ | `-10 .. +10 Nm` | 12 | data[6:7] |

发送 `FC` 为使能、`FD` 为失能、`FB` 为清故障、`FE` 为保存零点；正常位置控制帧始终按 MIT 的 `p | v | Kp | Kd | τ` 打包。当前上位机不提供 `FE` 永久零点命令入口。界面默认 τ=0。

## 电机错误日志

J4310 回包中的过压、欠压、过流、MOS/线圈过温、通信丢失和过载故障，以及 J4310、M3508、M2006 的反馈超时，都会由板端生成 `0x7F` 错误事件。上位机将这些故障以及电机动作失败统一追加写入 `上层分支/电机日志.log`，每条记录包含型号、FDCAN、节点 ID、错误或动作状态、板端毫秒时间戳和 PC 本地时间；普通电机反馈和成功的电机动作不会写入该日志。

板端正式协议解析层的换算关系如下。令 `rpm_to_rad_s = 2π / 60`、`rad_s_to_rpm = 60 / (2π)`，电流缩放因子为 `M3508: 20 / 16384 A/raw`、`M2006: 10 / 10000 A/raw`：

- 速度环：`Kp/Ki/Kd_board = GUI × current_scale × rad_s_to_rpm`，`I_limit_board = GUI × rpm_to_rad_s`，`output_limit_board = GUI × current_scale`。
- 位置环：`Kp/Ki/Kd_board = GUI × rpm_to_rad_s`，`I_limit_board` 保持不变，`output_limit_board = GUI × rpm_to_rad_s`。

上面的换算由 `User/Driver/PcLink/upper_pc_link.c` 执行；不能把 GUI 数值直接填入机构或电机端口常量，否则控制量量纲不一致。
