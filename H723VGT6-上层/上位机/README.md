# H723VGT6 上层控制台

这是 `H723VGT6-上层` 的 PC 端控制程序，使用 Tkinter 绘制界面，使用 `pyserial` 访问 CH340N 对应的虚拟串口。界面分为三个可切换页面：

- 机械臂：达妙 J4310 + 两个 M3508
- 开关门：一个 M2006
- 夹爪：一个 M2006

## 启动

Windows 上双击 `启动上位机.bat`，或在当前目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

Python 3.10 或更高版本可用。串口为 UART4，参数为 `115200 8N1`。浏览器不参与串口访问，因此不需要额外的本地服务器。

## 测试按键

机械臂页分别提供 J4310 与 M3508 #1/#2 的“输出轴正反 90° × 3”按键；开关门和夹爪页各有一个对应 M2006 测试按键。测试轨迹为：

```text
基准 + 90° -> 基准 - 90°   重复 3 次   -> 回到基准
```

测试命令每 50 ms 刷新一次，单个位置阶段保持 900 ms，测试角度均指输出轴角度，`90° = π/2 rad ≈ 1.5708 rad`。J4310 的 MIT `p_des`/`v_des` 是驱动器定义的输出轴位置/速度，单位分别为 `rad` 与 `rad/s`；M3508 目标位置由转子角度按 `3591/187` 减速比换算为输出轴角度（`rad`）；M2006 按 `36` 减速比换算为输出轴角度（`rad`）。这里的“输出轴角度”不是电机内部的“转子角度”；转子角度只用于编码器采样和减速比换算。J4310 的位置、速度、Kp、Kd、tau 和力矩限幅均可编辑并随扩展 MIT 字段发送；M3508/M2006 通过 `0x12` 位置命令选择板端已有的“位置环 -> 速度环 -> 电流命令”级联控制。一次扩展位置帧同时携带 J4310 与 M3508/M2006 目标和参数，板端在同一个 1 ms 控制周期内完成目标快照和 CAN 调度。

测试前必须架空机构、确认机械限位和急停链路有效。断开串口时程序发送急停，板端还会在超过 200 ms 没有有效上位机帧时停止远程输出。

点击“连接”后，上位机会先发送 `HANDSHAKE (0x03)` 请求（payload 为 ASCII `H723`），并等待板端返回同序列号的 `ACK (0x7E)`（payload 同为 `H723`）。收到匹配 ACK 前界面保持“握手中”，不会发送心跳或电机目标；只有收到 ACK 后才显示“已握手”并开始控制。握手成功后点击“断连”会停止测试、发送急停并关闭串口；握手超时则直接关闭串口。

## PC 二进制协议

帧格式与 `User/Driver/PcLink/pc_protocol.c` 一致，所有多字节字段为小端：

```text
A5 5A | version(u8) | type(u8) | sequence(u16) | length(u16) |
payload(length) | CRC16(u16)
```

CRC16 为 Modbus CRC（初值 `0xFFFF`，多项式 `0xA001`），覆盖 `version` 到 payload 的全部字节。

| 类型 | 值 | 说明 |
| --- | ---: | --- |
| HEARTBEAT | `0x01` | 空 payload，维持远程链路 |
| ESTOP | `0x02` | payload 为 `01`，进入急停 |
| HANDSHAKE | `0x03` | payload 为 ASCII `H723`，请求建立控制链路 |
| UPPER_CMD | `0x10` | 原有 V3 速度命令，保持兼容 |
| UPPER_POSITION_CMD | `0x12` | 位置命令，兼容 34 字节，当前发送 122 字节扩展 payload |
| ROBOT_STATE | `0x20` | 板端 20 字节状态回传 |
| ACK | `0x7E` | 握手确认：序列号与请求一致，payload 为 ASCII `H723` |

兼容位置命令 payload 为 `u16 enable_mask + 8 个 little-endian float`（34 字节）。当前上位机发送扩展位置命令，payload 为 `u16 enable_mask + 30 个 little-endian float`（122 字节）：

| 偏移 | 字段 | 单位 |
| ---: | --- | --- |
| 0 | 使能位：bit0 机械臂，bit1 开关门，bit2 夹爪 | - |
| 2 | J4310 目标位置（输出轴角度） | rad |
| 6 | J4310 目标角速度（输出轴） | rad/s |
| 10 | J4310 基准 Kp | - |
| 14 | J4310 基准 Kd | - |
| 18 | M3508 #1 位置（输出轴角度） | rad |
| 22 | M3508 #2 位置（输出轴角度） | rad |
| 26 | 开关门 M2006 位置（输出轴角度） | rad |
| 30 | 夹爪 M2006 位置（输出轴角度） | rad |

扩展位置命令的完整浮点顺序如下；与兼容布局相比，M3508/M2006 位置字段后移到浮点序号 6..9：

| 浮点序号 | 字段 | GUI 单位 |
| ---: | --- | --- |
| 4 | J4310 `tau` | Nm |
| 5 | J4310 力矩限幅 | Nm |
| 6..9 | M3508 #1/#2、开关门、夹爪位置 | rad |
| 10..14 | M3508 速度环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |
| 15..19 | M3508 位置环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |
| 20..24 | M2006 速度环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |
| 25..29 | M2006 位置环 Kp/Ki/Kd/积分限幅/输出限幅 | DJI_H723_VOFA GUI 单位 |

`0x10` 速度命令使用同样的偏移，但偏移 18/22/26/30 解释为 `rad/s`，并由原有速度模式处理。

## J4310 MIT 参数

板端 J4310 使用标准 8 字节 MIT CAN 帧，CAN 标准 ID 为电机逻辑 ID `3`，Master ID 为 `0`。`p_des` 与 `v_des` 均以 J4310 输出轴为基准，参数映射为：

上位机可编辑并发送全部 MIT 参数：`p_des`、`v_des`、`Kp`、`Kd`、前馈 `tau` 和力矩限幅。`tau` 默认 `0 Nm`，力矩限幅默认 `10 Nm`；后两项分别对应 MIT 帧力矩字段和板端安全裁剪范围。

| 字段 | 范围 | 位宽 | 打包位置 |
| --- | ---: | ---: | --- |
| 目标位置 p | `-12.5 .. +12.5 rad` | 16 | data[0:1] |
| 目标速度 v | `-30 .. +30 rad/s` | 12 | data[2:3] |
| Kp | `0 .. 500` | 12 | data[3:4] |
| Kd | `0 .. 5` | 12 | data[5:6] |
| 前馈力矩 τ | `-10 .. +10 Nm` | 12 | data[6:7] |

发送 `FC` 为使能、`FD` 为失能、`FB` 为清故障、`FE` 为保存零点；正常位置控制帧按 `p | v | Kp | Kd | τ` 打包。界面默认 τ=0。

## DJI_H723_VOFA GUI 参考 PID 参数

页面中的 M3508/M2006 参数表使用参考工程 `DJI_H723_VOFA` 的 GUI 单位，所有输入项均可修改，并随扩展 `0x12` 位置命令发送到 H723；板端收到后再换算为驱动内部单位。

### M3508 / C620（GUI 单位）

| 环路 | Kp | Ki | Kd | 积分限幅 | 输出限幅 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 速度环 | 80 | 40 | 0 | 100 | 16384 |
| 位置环 | 60 | 0 | 0 | 0 | 300 rpm |

### M2006 / C610（GUI 单位）

| 环路 | Kp | Ki | Kd | 积分限幅 | 输出限幅 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 速度环 | 350 | 250 | 0 | 0.5 | 10000 |
| 位置环 | 220 | 500 | 5 | 0.002 | 50 rpm |

`Vofa` 桥接层的换算关系如下。令 `rpm_to_rad_s = 2π / 60`、`rad_s_to_rpm = 60 / (2π)`，电流缩放因子为 `M3508: 20 / 16384 A/raw`、`M2006: 10 / 10000 A/raw`：

- 速度环：`Kp/Ki/Kd_board = GUI × current_scale × rad_s_to_rpm`，`I_limit_board = GUI × rpm_to_rad_s`，`output_limit_board = GUI × current_scale`。
- 位置环：`Kp/Ki/Kd_board = GUI × rpm_to_rad_s`，`I_limit_board` 保持不变，`output_limit_board = GUI × rpm_to_rad_s`。

上面的换算来自 `User/Application/Vofa/vofa_bridge.c`；不能把 GUI 数值直接填入 `upper_config.h`，否则控制量量纲不一致。

## H723 板端位置控制参数（实际单位）

以下数值是当前 `H723VGT6-上层/User/Config/upper_config.h` 和 `upper_motor_port.c` 实际下发的初始参数。参数顺序统一为 `Kp, Ki, Kd, 积分限幅, 输出限幅`。

### M3508 / C620

| 环路 | Kp | Ki | Kd | 积分限幅 | 输出限幅 | 输出单位 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 速度环 | 0.9325 | 0.4663 | 0 | 6 | 3 | A |
| 位置环 | 6.2832 | 0 | 0 | 0 | 15.708 | rad/s |

位置环输出的是速度目标，再进入速度 PID；电流总限幅为 `3 A`，位置环速度限幅为 `15.708 rad/s`。速度环启用固件中的专家 + 自适应在线增益调度，积分分离与条件抗饱和仍受上述积分/输出限幅约束。

### M2006 / C610

| 环路 | Kp | Ki | Kd | 积分限幅 | 输出限幅 | 输出单位 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 速度环 | 0.2865 | 0.0955 | 0 | 10 | 2 | A |
| 位置环 | 4.1888 | 0 | 0 | 0 | 10.472 | rad/s |

位置环输出的是速度目标，再进入速度 PID；电流总限幅为 `2 A`，位置环速度限幅为 `10.472 rad/s`。速度环启用固件中的自适应在线增益调度，积分分离与条件抗饱和仍受上述积分/输出限幅约束。

反馈超时为 `50 ms`，上位机命令超时为 `200 ms`。M3508 减速比为 `3591/187`，M2006 减速比为 `36`，位置单位均为输出轴 rad；对应的编码器原始角度称为转子角度。
