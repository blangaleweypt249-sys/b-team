# 系统说明

项目负责感知信息处理（定位、球检测、球-雷达融合测距），并通过串口网关将感知数据发送给 STM32 下位机。

## 目录说明

- `src/competition_perception/`：比赛定位与视觉感知包
  - `field_localizer.py`：将 FAST-LIO 里程计转换为比赛坐标系中的机器人位姿
  - `vision_detector.py`：检测 RGB-D 图像中的金色灵石
  - `field_visualizer.py`：在 RViz 中显示赛场边界与机器人实时位置
- `src/yolo/ball_perception/`：金球检测与测距包
  - `usb_camera_node.py`：USB 相机发布节点（技彩 MF100）
  - `ball_distance_node.py`：YOLOv8-seg 球检测 + MID360 雷达融合测距
  - `config/perception_params.yaml`：相机内参、外参、YOLO 模型路径配置
  - `launch/perception_launch.py`：球感知节点启动文件
- `src/competition_gateway/`：C++ 串口网关
  - 独占 `/dev/ttyUSB0` 串口
  - 将 ROS 话题数据（定位、球位置）封装为固定帧格式发送给 STM32
  - 接收 STM32 状态帧并发布连接状态

## 接口说明

| 方向 | 话题 | 类型 | 用途 |
| --- | --- | --- | --- |
| 输入 | `/fastlio2/lio_odom` | `nav_msgs/Odometry` | FAST-LIO 里程计输入 |
| 输出 | `/competition/field_pose` | `geometry_msgs/PoseStamped` | 机器人位姿（比赛坐标系） |
| 输出 | `/competition/current_zone` | `std_msgs/String` | 当前赛场区域 |
| 输入 | `/camera/color/image_raw` | `sensor_msgs/Image` | RGB 图像（灵石检测） |
| 输入 | `/camera/depth/image_raw` | `sensor_msgs/Image` | 深度图像（灵石测距） |
| 输出 | `/competition/vision/target` | `geometry_msgs/PointStamped` | 灵石三维点（前/左/上） |
| 输出 | `/competition/vision/overlay` | `sensor_msgs/Image` | 灵石识别叠加图 |
| 输出 | `/competition/field_markers` | `visualization_msgs/MarkerArray` | RViz 赛场显示 |
| 球感知输入 | `/camera/image_raw` | `sensor_msgs/Image` | USB 相机图像（YOLO 检测） |
| 球感知输入 | `/livox/lidar` | `sensor_msgs/PointCloud2` | MID360 雷达点云 |
| 球感知输出 | `/perception/ball_distance` | `std_msgs/Float32` | 球距离（米） |
| 球感知输出 | `/perception/ball_position` | `geometry_msgs/PointStamped` | 球 3D 位置（雷达坐标系） |
| 球感知输出 | `/perception/ball_overlay` | `sensor_msgs/Image` | 球检测+测距叠加图 |
| 串口输出 | `/competition/serial/controller_connected` | `std_msgs/Bool` | STM32 连接状态 |
| 串口输出 | `/competition/serial/controller_state` | `std_msgs/UInt8` | STM32 状态机状态 |
| 串口输出 | `/competition/serial/controller_error` | `std_msgs/UInt8` | STM32 错误码 |

## 构建与运行

### 环境准备

```bash
source /opt/ros/humble/setup.bash
cd /home/husky/TR
```

### 编译所有包

```bash
colcon build --packages-select competition_perception competition_gateway ball_perception --cmake-args -DBUILD_TESTING=OFF
source install/setup.bash
```

### 单独启动球感知（相机+雷达融合测距）

```bash
ros2 launch ball_perception perception_launch.py
```

此命令将启动：
- `usb_camera_node`：USB 相机发布（640x480，30fps）
- `ball_distance_node`：YOLOv8-seg 球检测 + MID360 点云投影测距

### 启动串口网关

```bash
ros2 run competition_gateway serial_gateway
```

串口网关订阅：
- `/competition/field_pose`：机器人位姿
- `/perception/ball_position`：球 3D 位置

并将数据封装为 32 字节感知帧通过 `/dev/ttyUSB0` 发送给 STM32（50Hz）。

### 完整系统启动

需同时启动：
1. FAST-LIO 里程计节点
2. RGB-D 相机节点
3. MID360 雷达节点
4. 比赛感知栈：`ros2 launch competition_perception competition_stack.launch.py`
5. 球感知栈：`ros2 launch ball_perception perception_launch.py`
6. 串口网关：`ros2 run competition_gateway serial_gateway`

## 串口协议

感知帧格式（32 字节）：

| 偏移 | 字段 | 说明 |
| --- | --- | --- |
| 0-1 | 帧头 | `0xAA 0x55` |
| 2 | 帧类型 | `0x10` (感知帧) |
| 3 | 序号 | 递增，溢出从 0 开始 |
| 4 | 有效位 | bit0: 定位有效, bit1: 球位置有效 |
| 5-16 | 定位 | field_x/y/z (float32) |
| 17-28 | 球位置 | target_x/y/z (float32, 小端) |
| 29 | 校验 | 偏移 2-28 累加和 |
| 30-31 | 帧尾 | `0x0D 0x0A` |

详细协议定义见 [串口通信协议.md](docs/串口通信协议.md)。
