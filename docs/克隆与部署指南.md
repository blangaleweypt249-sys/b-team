# 克隆与部署指南

本文档说明如何从零开始克隆、配置、编译并启动本工作区。

---

## 硬件清单

| 设备 | 型号 | 备注 |
|------|------|------|
| 激光雷达 | Livox MID360 | 以太网，IP 192.168.1.175 |
| 相机（金球检测） | 技彩 MF100 | USB，`/dev/video2`，640×480 |
| RGB-D 相机（红蓝块检测） | Orbbec Gemini2 | USB |
| 串口下位机 | STM32 | USB 转串口，`/dev/ttyUSB0`，115200 bps |

## 一、克隆仓库

```bash
git clone git@github.com:blangaleweypt249-sys/b-team.git
cd b-team
git checkout 小电脑分支
```

### 子模块（需手动拉取）

FAST-LIO 和 livox_ros_driver2 是子模块，克隆后目录为空，需手动拉取：

```bash
# 初始化子模块配置
git submodule init
# 拉取子模块代码（需子模块远程仓库可访问）
git submodule update
```

如果子模块远程仓库不可用，手动 clone 到对应目录：

```bash
# FAST-LIO2 ROS2
git clone git@github.com:huskyjk/FAST_LIO2_ROS2.git src/FAST_LIO2_ROS2
# Livox 雷达驱动
git clone git@github.com:huskyjk/livox_ros_driver2.git src/livox_ros_driver2
```

### 模型权重文件

YOLO 模型权重文件（.pt）已直接包含在仓库中，克隆后即可使用，无需额外操作：

```
src/yolo/runs/segment/gold_ball/weights/best.pt   # 金球分割模型（6.5MB）
src/yolo/runs/segment/blue_red/weights/best.pt     # 红蓝块分割模型（6.5MB）
src/yolo/yolov8n-seg.pt                             # YOLOv8n 预训练模型（7MB）
```

## 二、环境依赖

| 项目 | 版本要求 |
|------|----------|
| 系统 | Ubuntu 22.04 (Jammy) |
| ROS | Humble |
| Python | 3.10+ |
| C++ 编译器 | GCC 11+ |

### 安装 ROS2 Humble

参考官方文档：<https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debians.html>

### 安装系统级依赖

```bash
sudo apt update
sudo apt install -y \
    ros-humble-rviz2 \
    ros-humble-cv-bridge \
    ros-humble-vision-opencv \
    ros-humble-sensor-msgs-py \
    ros-humble-geometry-msgs \
    ros-humble-nav-msgs \
    ros-humble-std-msgs \
    ros-humble-ament-index-python \
    v4l-utils \
    libserial-dev \
    python3-pip
```

### 安装 Python 依赖

```bash
pip3 install --upgrade pip
pip3 install \
    ultralytics \
    numpy \
    opencv-python \
    opencv-contrib-python \
    pyyaml \
    pyorbbecsdk
```

> **pyorbbecsdk** 是 Orbbec Gemini2 RGB-D 相机的 Python SDK，通过 pip 直接安装（约 68MB），
> 无需源码。金球检测（ball_perception）不依赖此包。

## 三、编译工作区

```bash
cd TR
source /opt/ros/humble/setup.bash

# 编译全部包（首次编译）
colcon build --symlink-install --cmake-args -DBUILD_TESTING=OFF

# 编译完成后 source install
source install/setup.bash
```

增量编译单独包：

```bash
colcon build --packages-select common_launch_pkg ball_perception block_perception --symlink-install
```

## 四、启动系统

### ✅ 集成启动：一键启动全部

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash

ros2 launch common_launch_pkg common_launch.py
```

启动分为 3 个阶段按序执行，总耗时约 12 秒：

| 阶段 | 时间 | 模块 | 作用 |
|------|------|------|------|
| 1 | 0s | 雷达驱动 | MID360 驱动 → FAST-LIO 里程计 → 发布 `/Odometry` |
| 2 | 6s | 感知节点 | 两台相机启动 → 球检测融合 / 红蓝块检测融合 → 场地定位 |
| 3 | 12s | 信息发布 | 串口网关启动 → 50Hz 向 STM32 发送感知数据 |

#### 可选启动参数

```bash
# 启动 RViz 可视化
ros2 launch common_launch_pkg common_launch.py rviz:=true

# 指定其他串口或波特率
ros2 launch common_launch_pkg common_launch.py serial_device:=/dev/ttyUSB1 baudrate:=921600
```

---

### 🛠 独立启动各模块（调试用）

当你只需要调试某个模块时，使用对应的独立 launch 命令：

#### 1. 仅启动雷达驱动 + FAST-LIO 里程计

```bash
ros2 launch common_launch_pkg lidar_driver.launch.py
# 参数: rviz:=true  xfer_format:=0 (0=PointCloud2, 1=CustomMsg)
```

#### 2. 仅启动感知节点（定位 + 球检测 + 红蓝块检测）

⚠️ 需要先运行雷达驱动，否则球检测测距与场地定位无法正常工作。

```bash
ros2 launch common_launch_pkg perception_nodes.launch.py
```

#### 3. 仅启动串口网关（信息发布）

⚠️ 需要先运行感知节点，否则网关将因数据超时而清除所有有效位。

```bash
ros2 launch common_launch_pkg serial_gateway.launch.py
# 参数: serial_device:=/dev/ttyUSB0  baudrate:=115200
```

#### 4. 其他包的独立 launch（兼容旧模式）

```bash
ros2 launch fyt_pos fyt_pos.launch.py                  # 仅定位 + 可视化
ros2 launch ball_perception perception_launch.py        # 仅 USB 相机 + 球检测
ros2 launch block_perception perception_launch.py       # 仅 Orbbec 相机 + 红蓝块检测
ros2 run competition_gateway serial_gateway             # 仅串口网关 (ros2 run)
```

## 六、常见问题

### 1. 雷达驱动无法连接

请确认：
- 电脑 IP 已设置为 `192.168.1.50/24`（静态）
- 雷达已上电，网线插好，PING `192.168.1.175` 通

### 2. 串口报错 `Permission denied: '/dev/ttyUSB0'`

```bash
sudo usermod -aG dialout $USER
# 重新登录生效
```

### 3. YOLO 模型加载失败：`FileNotFoundError`

确认两个 `best.pt` 文件存在（[见克隆与模型权重](#一克隆仓库)）。模型会在编译时随包安装到：

```
install/ball_perception/share/ball_perception/models/best.pt
install/block_perception/share/block_perception/models/best.pt
```

如果缺失，重新 `colcon build --packages-select ball_perception block_perception`。

### 4. USB 相机打不开

```bash
# 列出相机设备
v4l2-ctl --list-devices
# 修改 ball_perception/launch/perception_launch.py 中的 device_id
```

### 5. 如何查看某个话题是否正常？

```bash
ros2 topic echo /competition/field_pose           # 场地位姿
ros2 topic echo /perception/ball_position          # 金球位置
ros2 topic echo /competition/serial/controller_connected  # STM32 连接状态
```

## 七、包结构

```
src/
├── common_launch_pkg/             ← 集成启动包（4 个 launch 文件）
│   └── launch/
│       ├── common_launch.py       ← 集成一键启动
│       ├── lidar_driver.launch.py ← 独立：雷达驱动 + 里程计
│       ├── perception_nodes.launch.py ← 独立：所有感知节点
│       └── serial_gateway.launch.py   ← 独立：信息发布（串口网关）
├── competition_gateway/           ← C++ 串口网关
├── fyt_pos/                       ← 场地位姿解算与可视化
├── livox_ros_driver2/             ← MID360 雷达驱动 (submodule)
├── FAST_LIO2_ROS2/                ← FAST-LIO 里程计 (submodule)
└── yolo/
    ├── ball_perception/           ← 金球检测 + 雷达融合测距
    ├── block_perception/          ← 红蓝块检测 + Orbbec 深度测距
    └── runs/segment/*/weights/    ← YOLO 模型权重（金球 + 红蓝块）
```
