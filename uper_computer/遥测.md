# 机器人运动通信协议

本文档记录电脑上位机当前使用的速度指令协议，供后续下位机接收程序和遥控程序共用。当前版本只定义控制端到机器人的速度指令，尚未定义机器人返回的遥测帧。

## 串口参数

| 参数 | 数值 |
|---|---|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |
| 运动保活周期 | 100 ms，10 Hz |

无线 DAPLink 工作在透明串口模式，协议不包含 AT 指令或无线模块配置命令。

## 坐标系

- `+vx`：机器人前进。
- `+vy`：机器人向左平移。
- `+wz`：机器人逆时针旋转。

三个字段表示机器人整体运动方向，不是单个车轮 RPM。当前下位机沿用现有底盘控制量，不对实际物理速度做标定。

## 速度指令帧

每帧固定 9 字节，多字节整数采用小端序：

| 字节偏移 | 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | `header_0` | `uint8_t` | - | 固定 `0xA5` |
| 1 | `header_1` | `uint8_t` | - | 固定 `0x5A` |
| 2-3 | `vx_cmd` | `int16_t` | 控制量 | X 轴整体运动指令 |
| 4-5 | `vy_cmd` | `int16_t` | 控制量 | Y 轴整体运动指令 |
| 6-7 | `z_cmd` | `int16_t` | 控制量 | Z 轴整体旋转指令 |
| 8 | `checksum` | `uint8_t` | - | 字节 2-7 的逐字节异或 |

校验计算：

```c
checksum = frame[2] ^ frame[3] ^ frame[4] ^
           frame[5] ^ frame[6] ^ frame[7];
```

帧头不参与校验。负数使用有符号 16 位补码表示。

## 按键映射

| 按键 | `vx` | `vy` | `wz` |
|---|---:|---:|---:|
| W | 正 | 0 | 0 |
| S | 负 | 0 | 0 |
| A | 0 | 正 | 0 |
| D | 0 | 负 | 0 |
| Q | 0 | 0 | 正 |
| E | 0 | 0 | 负 |

W/S、A/D、Q/E 各自同时按下时，对应轴速度为零。斜向平移时两个轴均乘以 `1/sqrt(2)`，保证合速度大小不超过设定的平移速度。

## 速度范围

上位机设置沿用参考工程：

| 参数 | 最小值 | 最大值 | 默认值 | 步进 |
|---|---:|---:|---:|---:|
| 平移速度 | 0.05 m/s | 5.00 m/s | 0.05 m/s | 0.05 m/s |
| 旋转速度 | 0.01 rad/s | 10.00 rad/s | 0.01 rad/s | 0.01 rad/s |

打包前分别乘以 1000 并四舍五入，转换为 `mm/s` 和 `mrad/s` 整数。

## 示例

| 指令 | 9 字节十六进制帧 |
|---|---|
| 停止 | `A5 5A 00 00 00 00 00 00 00` |
| 以 0.05 m/s 前进 | `A5 5A 32 00 00 00 00 00 32` |
| 以 0.05 m/s 后退 | `A5 5A CE FF 00 00 00 00 31` |
| 以 0.05 m/s 右移 | `A5 5A 00 00 CE FF 00 00 31` |
| 以 0.01 rad/s 逆时针旋转 | `A5 5A 00 00 00 00 0A 00 0A` |
| 默认速度前进并右移 | `A5 5A 23 00 DD FF 00 00 01` |

## 接收端要求

1. 按字节搜索连续帧头 `A5 5A`，找到后再接收剩余 7 字节。
2. 帧长度和异或校验均正确后，才更新速度目标。
3. 上电后的目标速度必须初始化为零。
4. 建议超过 200 ms 未收到合法帧时，将三个速度目标全部置零。
5. 校验失败时丢弃当前帧并重新搜索帧头，不得沿用错误帧中的速度。
6. 控制输入变化时立即发送一帧；运动期间以 10 Hz 发送保活帧，静止状态不需要周期发送。

## 后续遥测扩展

机器人到控制端的状态回传尚未设计。在定义电压、姿态、轮速或故障状态前，应另行分配帧类型和长度字段，不能直接改变本速度帧的 9 字节布局，以免现有电脑端和未来遥控端产生兼容性问题。
