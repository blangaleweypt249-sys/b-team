# 人工直线路径辅助与安全层

本目录只从 `arena/01a00390-taisheng` 的 `user/path_planner/path_config.h`
提取场地地图。没有复制该分支的样条曲线、自动跟踪、FSM、小电脑定位或
自动驾驶控制；底盘平移指令始终来自现有 LoRa 遥控器。

## 坐标与一次性激光定点

- 地图坐标：X 向右，Y 向前；正常控制时 yaw 锁定为 `0°`。
- 场地：`3.0 m × 6.0 m`。
- 机器人：长 `0.617 m`、宽 `0.440 m`。
- 左 DT35 安装在中心左方 `0.175 m`，扫描西边界内侧面
  `x = 0.049 m`。启动时只等待左 DT35 按接收时间戳收齐 3 个新样本，
  取中值作为 X 定点距离；该采样独立于安全限速的三点保守最小值。
- 初始机器人中心 Y 恒为车长一半，即 `0.6170 / 2 = 0.3085 m`。
- 前 DT35 不参与、不等待也不校验初始定位。启动位置的 `20 cm` 无法区分
  真实距离和超量程饱和；前光仅保留运行期 `+Y` 动态安全限速职责。

设左光中值距离为 `d_l`，定点周期 IMU 实测 yaw 为 `ψ`，则机器人中心为：

```text
x = 0.049 + (0.175 + d_l) × cos(ψ)
y = 0.6170 / 2 = 0.3085
```

实现还计算左光墙面交点，确认其落在西边界有效 Y 范围内；不再计算或校验
前光到墙 B 的初始定位几何。定点只成功一次：成功时记录融合里程计位置
`(odom_x, odom_y)`，保存地图偏移
`(x - odom_x, y - odom_y)`；之后地图坐标始终为该偏移加实时融合位置，
不再用激光重置，也不依赖上位机绝对定位。

`0.2700 m` 与 `0.3285 m` 现在只表示地图碰撞计算的车体边界净空（半车宽
加 `5 cm`、半车长加 `2 cm`），不再表示启动位置。

`path_map.c` 保留参考地图的 4 面边界墙与 3 段内墙：

| 墙 | 矩形范围 (m) |
| --- | --- |
| 南 | `(0,0)–(3,0.049)` |
| 北 | `(0,5.951)–(3,6)` |
| 西 | `(0,0)–(0.049,6)` |
| 东 | `(2.951,0)–(3,6)` |

## 镜像地图（对抗侧，场地互换）

对抗赛双方场地互为左右镜像，换场后机器人贴**东墙**起步、车头仍朝 `+Y`。
镜像侧地图由 `PathMap_SetMirrored(true)` 选择，`GetWalls/GetRoute/`
`SegmentReached/RayClearance` 全部随之切换：

| 项 | 常规侧（贴西墙） | 镜像侧（贴东墙） |
| --- | --- | --- |
| 墙 1 | `(1.05,1.07)–(3,1.12)`（贴东墙） | `(0,1.07)–(1.95,1.12)`（贴西墙） |
| 墙 B | `(0,2.075)–(2,2.125)`（贴西墙） | `(1,2.075)–(3,2.125)`（贴东墙） |
| 墙 C | `(1.05,3.075)–(3,3.125)`（贴东墙） | `(0,3.075)–(1.95,3.125)`（贴西墙） |
| 路线 | 上、右、上、左、上、右 | 上、左、上、右、上、左（X 段方向与终点取镜像：`0.52 / 2.64 / 2.50`） |
| 起点 X | `0.049 + 0.175 + d_l`（实测） | `2.626 m`（假定贴东墙对称摆放） |

**场地要求**：镜像侧跑之前，需要把 3 段内墙物理摆放到上表镜像位置
（墙 1、墙 C 贴西墙，墙 B 贴东墙）；4 面边界墙不动。机器人贴东墙起步，
与西墙间距约 `15 cm`（与常规侧对称）。

### 自动识别与锚定

- 左 DT35 子板超量程时输出钳在 `20 cm`，饱和读数视为“没有目标”，
  不参与常规侧左光定点。镜像侧左光面向空旷场地（西墙在 `2.4 m` 外），
  因此永远没有样本，常规侧左光定点不会误触发。
- 未定点期间前光读数首次降到 `20 cm` 以下（首次扫到墙）时做一次侧别
  判定：左光有目标（≥3 个样本且中值 `< 20 cm`）→ 常规侧，继续等左光
  锚定；左光无目标 → 镜像侧。
- 镜像侧锚定不依赖 yaw 和左光：X 用假定贴东墙起点
  `PATH_MAP_MIRRORED_START_X_M = 2.626 m`，Y 用前光安装偏移
  `0.225 m` 加实测距离反算第一堵前墙（镜像场地上是贴东墙的墙 B，
  南面 `y = 2.075 m`）的位置：
  `y = 2.075 − 0.225 − d_front`。锚定后同样只跟随融合里程计。
- 镜像侧左光无目标时**跳过左光限速**（20 cm 饱和是假障碍）；一旦出现
  真实目标（`< 20 cm`）限速恢复。常规侧保持原行为：20 cm 饱和仍按
  “墙在量程边界”保守限速。
- 若常规侧摆位离西墙超过 `20 cm`（左光读不到墙），会自动误判为镜像侧；
  摆位必须保证左光能看到西墙。

## 按键 1 单轴模式

本机控制帧 `payload[4] bit0` 使用按下沿切换当前地图直线段的单轴限制。
按住不会重复切换，松开后再次按下可人工解除。

参考路线中的圆弧不适用于 yaw=0，因此按墙端通道改为以下纯直线分段：

| 段 | 允许轴 | 里程计终点 |
| --- | --- | --- |
| 0 | Y | `y = 1.600 m`（墙 1/墙 B 走廊安全中心，膨胀后走廊为 `1.4485–1.7465 m`） |
| 1 | X | `x = 2.480 m` |
| 2 | Y | `y = 2.600 m` |
| 3 | X | `x = 0.360 m`（负向） |
| 4 | Y | `y = 3.700 m` |
| 5 | X | `x = 0.500 m` |

模式开启时只清零非当前规划轴（在**地图系**清轴，掉头后仍然清对轴），
沿当前轴的正反向仍由人控制。距当前段终点不足 `0.10 m` 或越过终点时，
模块**自动解除**单轴约束——不停车、不要求摇杆回中，驾驶员可以直接把
摇杆过渡到下一段方向连贯行驶。注意：段终点不再自动刹停，满杆换向的
动量与四轮暂态可能贴擦膨胀带边缘，换向建议先收杆。LoRa 超时仍会取消
模式并停车。

## yaw=0 与回程

所有遥控及其他速度来源的旋转分量都由本层置为 0，肩键不再产生旋转。
IMU 进入 READY 或离线恢复后，本层重新使能原有 yaw 闭环并把目标设为
`0°`。初始激光定点例外：几何反算使用该周期 IMU 实测 yaw 投影安装偏移
与射线，而不是假定机器人已经精确为 `0°`。本模块没有肩键使能、选轴或
取消逻辑。

**坐标系约定**：`Chassis_SetVelocity` 的 vx/vy 是**车体系**（X 向右、
Y 向前），DT35 也装在车体上；因此激光限速始终按车体分量判断（前光只
限制 `vy>0`，左光只限制 `vx<0`），与车头朝向无关。凡涉及地图几何的
计算（地图净空方向、单轴清轴）都先用实测 yaw 把命令旋到地图系再处理，
掉头 180° 后自动正确取反。单轴模式在**地图系**清除非规划轴，掉头残差
不会泄漏横向分量。

## 回程（自动检测车头朝向：倒车回程或正向回程）

去程 6 段走完后（`route_complete`），按遥控**按键 2（六键 bit1）**进入
回程模式。**不必在终点立刻回程**：可以继续前进完成任务，之后再按
按键 2，回程路线会从按键时所在位置引导回起点（只要车在墙间走廊内，
任务点可以在去程终点之后任意位置）。

- **自动检测车头朝向**：进入回程时按当前 yaw 自动选择——车头靠近
  `+Y`（|yaw|≤90°）则**倒车回程**（yaw 锁 `0°`，不掉头，立即可走）；
  车头靠近 `-Y` 则车头朝 `-Y` **正向回程**（yaw 锁 `180°`）。运行中
  实测 yaw 偏离当前锁定角超过 `100°`（含 10° 滞回，例如驾驶员用肩键
  调头）时自动切换到另一朝向，`return_reverse` 诊断位随之更新。
- **肩键微调**：回程模式**不锁肩键**——肩键旋转指令（±10）直通底盘，
  `CalcOmega` 手动旋转优先并让保持目标跟随当前航向，本层不再回拉
  目标角；松开后保持在微调后的航向。微调超出对齐允差 `5°` 会暂时
  闸住平移，转回允差内自动恢复。去程仍锁 z=0。
- **转向期间**（`return_yaw_aligned` 为假）平移命令被忽略；对齐允差
  `5°`（机器人斜置时轴对齐包络显著变宽，`20°` 时半宽由 0.22 m 增至
  0.31 m，会吃光安全裕量）。倒车回程无需转向，立即对齐。进入回程
  触发的 `Chassis_StopAll` 急停闩锁由底盘在整组清零一拍后自动解除
  （`chassis_main.c`），保证 `CalcOmega` 旋转注入通道可用。地图坐标
  始终实时跟随里程计。
- **回程路线**：常规侧 `X-0.36 → Y-2.60 → X+2.48 → Y-1.60 → X-0.374 →
  Y-0.3085`；镜像侧为对应镜像。按键 1 照常逐段切换单轴约束（靠近段
  终点自动解除）。回程操纵按车体系：正向回程（车头朝 `-Y`）向地图
  `-Y` 走推车体 `+Y`；倒车回程（车头朝 `+Y`）向地图 `-Y` 走推车体
  `-Y`（拉杆倒车）。
- **激光保护（车体系不变）**：前光永远限制车体 `+Y`、左光永远限制
  车体 `-X`。左光 `20 cm` 饱和是否当"墙在量程边界"保守限速由左光
  实际面向决定（车头靠近 `+Y` 时左光朝西、靠近 `-Y` 时朝东）：面向
  本侧近墙（常规=西、镜像=东）保守限速，面向空旷场地只对 `<20 cm`
  真实目标限速。**倒车方向（车尾）没有激光**，倒车回程只有静态地图
  净空保护。
- **沿墙滑动**：中心因惯性/漂移进入膨胀墙带后，只禁止继续向墙内的
  分量；主方向被挡时限速器自动只保留地图系主轴分量沿墙滑动，不会
  把机器人锁死在膨胀带内。
- **漂移校正（仅正向回程）**：末段车头朝起始贴靠面（地图 `y = 0`，
  初始中心 Y=车长一半即由该面得出），前光距离 `< 20 cm` 时用
  `y = 0.225 + d_front` 实时校正 Y；镜像侧左光读到东墙时用
  `x = 2.951 − 0.175 − d_left` 实时校正 X。倒车回程两支激光都朝外，
  末段完全依赖里程计，精度受漂移与锚定量化（整 cm 截断，≤1 cm）
  限制。
- **回到起点判定**：正向回程用前光贴面兜底——前 DT35 凹进车头面
  `8.35 cm`，按 `5°` 残差斜置投影后贴面读数上限 `10.2 cm`，读数
  `≤ 10 cm` 且地图 Y 在起点附近即判定；末段前光基础净距切换为贴靠
  基距 8.35 cm，逼近速度随读数收敛到 0。倒车回程（无激光）按地图
  `Y ≤ 起点 + 1 cm` 判定（与锚定量化误差同级）。南向净空线在末段
  收窄到起点中心 Y − 15 mm，为里程计蠕行越过段终点留出硬停距离。
- **回到起点**：地图坐标强制归零到**起点位姿**（常规侧=锚定点；
  镜像侧=贴东墙起点 `(2.626, 0.3085)`，锚定点在中途不可用作归零
  目标），吸收全程里程计漂移，`return_complete` 置位。再按一次
  按键 2 退出回程、重新开始去程。

## 动态安全距离

前 DT35（`0x40`）只限制 `+Y` 前进分量；左 DT35（`0x41`）只限制
`-X` 向左分量。反方向离开障碍的命令不会被对应激光阻止。限速使用：

```text
d_safe = d_base + v × 0.080 s + v² / (2 × 2.0 m/s²)
```

- 前基础净距：`12 cm`；释放滞回到 `14 cm`。
- 左基础净距：`10 cm`；释放滞回到 `12 cm`。
- 速度取编码器实测朝障碍速度与当前请求速度中较大者计算动态需求；输出
  速度由实测距离反解公式后限幅。若实测逼近速度仍高于该距离允许值超过
  `0.03 m/s`，立即触发底盘制动；进入硬阻挡时若上一安全输出仍朝向障碍，
  即使里程计暂时无效也制动。反向逃离命令保留，横移不能掩盖逼近惯性。
- DT35 子板实际每 `50 ms` 更新，输出被钳在 `5–20 cm`。安全层保留最近
  3 点的保守最小值：距离减小首帧生效，距离增大需覆盖旧样本后才释放。
  `0` 绝不解释为“无回波自由”；若在线状态下读到异常 0，本层钳为 `5 cm`。
- 由于最大读数只有 `20 cm`，前进高速不能得到足够制动距离，即使读数为
  20 cm 也可能被限速，这是有意的安全行为。
- 按用户要求，任一激光离线时**不因离线停车**，仅在诊断中标记 offline，
  并跳过该方向的激光限速。

地图静态墙另作为无激光方向的辅助保护：把车体命令用实测 yaw 旋到地图
系后，按机器人外形膨胀内墙并对行进方向做射线净空限速；已在膨胀带内
时只禁止继续向墙内的分量，沿墙切向平移保持可用（否则一次越界就会被
锁死在膨胀带内）。它依赖纯里程计，会随漂移降低精度，不能代替对实际
障碍的观察；右侧和后方没有 DT35，不能宣称具备动态障碍激光保护。
另外注意：段间直角换向满杆起步时，四轮各自独立跟踪目标转速，反转轮
滞后会产生约 10–15 cm 的横向暂态漂移；换向起步建议先半杆再加速。

## 接入与诊断

- `Path_Init()`：FreeRTOS 创建任务前调用。
- `Path_SubmitRemoteCommand()`：LoRa 本机控制帧提交摇杆和六键。
- `Path_Run1ms()`：在融合里程计每 1 ms 更新后执行，并把变化后的安全
  输出提交给底盘。
- `Path_NotifyRemoteOffline()`：LoRa 200 ms 超时通知。
- `Path_ReplaceNonRemoteCommand()`：无小电脑模式下防止原上位机速度协议
  旁路人工安全输出；动作协议不受影响。
- `Path_GetDiagnostics()`：读取定点有效性、左光样本数/中值距离/墙面交点、
  分段、地图位姿、镜像侧标志 `map_mirrored`、回程标志 `return_mode`/
  `return_yaw_aligned`/`return_complete`/`return_reverse`（倒车回程）、
  激光在线/安全距离、动态限速、
  yaw 锁定以及原始/输出指令。常规侧兼容保留的前光初始样本、距离和交点
  字段恒为 `0`；镜像侧前光初始距离为锚定时的实测值。
