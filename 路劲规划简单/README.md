# 人工直线路径辅助与安全层

本目录只从 `arena/01a00390-taisheng` 的 `user/path_planner/path_config.h`
提取场地地图。没有复制该分支的样条曲线、自动跟踪、FSM、小电脑定位或
自动驾驶控制；底盘平移指令始终来自现有 LoRa 遥控器。

## 坐标与一次性激光定点

- 地图坐标：X 向右，Y 向前；正常控制时 yaw 锁定为 `0°`。
- 场地：`3.0 m × 6.0 m`。
- 机器人：长 `0.617 m`、宽 `0.440 m`。
- 前 DT35 安装在机器人中心前方 `0.225 m`，扫描墙 B 南侧面
  `y = 2.075 m`；左 DT35 安装在中心左方 `0.175 m`，扫描西边界
  内侧面 `x = 0.049 m`。
- 启动时前、左两路各按接收时间戳收齐 3 个新样本，分别取中值作为定点
  距离。该中值采样独立于安全限速使用的三点保守最小值。

设前、左中值距离分别为 `d_f`、`d_l`，定点周期 IMU 实测 yaw 为 `ψ`，
则机器人中心位置为：

```text
x = 0.049 + (0.175 + d_l) × cos(ψ)
y = 2.075 - (0.225 + d_f) × cos(ψ)
```

实现还计算两条射线的墙面交点，确认前光束落在墙 B 的 X 范围内、左光束
落在西边界有效 Y 范围内。定点只成功一次：成功时记录融合里程计位置
`(odom_x, odom_y)`，保存地图偏移
`(x - odom_x, y - odom_y)`；之后地图坐标始终为该偏移加实时融合位置，
不再用激光重置，也不依赖上位机绝对定位。

`0.2700 m` 与 `0.3285 m` 现在只表示地图碰撞计算的车体边界净空（半车宽
加 `5 cm`、半车长加 `2 cm`），不再表示启动位置。

`path_map.c` 保留参考地图的 4 面边界墙与 3 段内墙：

| 墙 | 矩形范围 (m) |
| --- | --- |
| 南 | `(0,0)–(3,0.049)` |
| 北 | `(0,5.951)–(3,6)` |
| 西 | `(0,0)–(0.049,6)` |
| 东 | `(2.951,0)–(3,6)` |
| 墙 1 | `(1.05,1.07)–(3,1.12)` |
| 墙 B | `(0,2.075)–(2,2.125)` |
| 墙 C | `(1.05,3.075)–(3,3.125)` |

## 按键 1 单轴模式

本机控制帧 `payload[4] bit0` 使用按下沿切换当前地图直线段的单轴限制。
按住不会重复切换，松开后再次按下可人工解除。

参考路线中的圆弧不适用于 yaw=0，因此按墙端通道改为以下纯直线分段：

| 段 | 允许轴 | 里程计终点 |
| --- | --- | --- |
| 0 | Y | `y = 1.650 m` |
| 1 | X | `x = 2.480 m` |
| 2 | Y | `y = 2.600 m` |
| 3 | X | `x = 0.360 m`（负向） |
| 4 | Y | `y = 3.700 m` |
| 5 | X | `x = 0.500 m` |

模式开启时只清零非当前规划轴，沿当前轴的正反向仍由人控制。融合里程计
检测到越过当前终点后，模块自动取消单轴模式、调用底盘停止，并要求摇杆
先回中再接受下一条平移命令，避免操作者忘记解除。LoRa 超时也会取消模式。

## yaw=0

所有遥控及其他速度来源的旋转分量都由本层置为 0，肩键不再产生旋转。
IMU 进入 READY 或离线恢复后，本层重新使能原有 yaw 闭环并把目标设为
`0°`。初始激光定点例外：几何反算使用该周期 IMU 实测 yaw 投影安装偏移
与射线，而不是假定机器人已经精确为 `0°`。本模块没有肩键使能、选轴或
取消逻辑。

## 动态安全距离

前 DT35（`0x40`）只限制 `+Y` 前进分量；左 DT35（`0x41`）只限制
`-X` 向左分量。反方向离开障碍的命令不会被对应激光阻止。限速使用：

```text
d_safe = d_base + v × 0.080 s + v² / (2 × 2.0 m/s²)
```

- 前基础净距：`12 cm`；释放滞回到 `14 cm`。
- 左基础净距：`10 cm`；释放滞回到 `12 cm`。
- 速度取编码器实测朝障碍速度与当前请求速度中较大者计算动态需求；输出
  速度由实测距离反解公式后限幅。若实测逼近速度仍高于该距离允许值超过
  `0.03 m/s`，立即触发底盘制动；进入硬阻挡时若上一安全输出仍朝向障碍，
  即使里程计暂时无效也制动。反向逃离命令保留，横移不能掩盖逼近惯性。
- DT35 子板实际每 `50 ms` 更新，输出被钳在 `5–20 cm`。安全层保留最近
  3 点的保守最小值：距离减小首帧生效，距离增大需覆盖旧样本后才释放。
  `0` 绝不解释为“无回波自由”；若在线状态下读到异常 0，本层钳为 `5 cm`。
- 由于最大读数只有 `20 cm`，前进高速不能得到足够制动距离，即使读数为
  20 cm 也可能被限速，这是有意的安全行为。
- 按用户要求，任一激光离线时**不因离线停车**，仅在诊断中标记 offline，
  并跳过该方向的激光限速。

地图静态墙另作为无激光方向的辅助保护：按机器人外形膨胀内墙并对行进
方向做射线净空限速。它依赖纯里程计，会随漂移降低精度，不能代替对实际
障碍的观察；右侧和后方没有 DT35，不能宣称具备动态障碍激光保护。

## 接入与诊断

- `Path_Init()`：FreeRTOS 创建任务前调用。
- `Path_SubmitRemoteCommand()`：LoRa 本机控制帧提交摇杆和六键。
- `Path_Run1ms()`：在融合里程计每 1 ms 更新后执行，并把变化后的安全
  输出提交给底盘。
- `Path_NotifyRemoteOffline()`：LoRa 200 ms 超时通知。
- `Path_ReplaceNonRemoteCommand()`：无小电脑模式下防止原上位机速度协议
  旁路人工安全输出；动作协议不受影响。
- `Path_GetDiagnostics()`：读取定点有效性/样本数/中值距离/墙面交点、分段、
  地图位姿、激光在线/安全距离、动态限速、yaw 锁定以及原始/输出指令。
